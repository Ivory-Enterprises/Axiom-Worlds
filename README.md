# 🌎 Axiom Worlds

### Imagine a Game. Build a World. Play Your Creation.

Axiom Worlds is a planned AI-powered game creation platform that allows users to create their own single-player games using simple text prompts.

Describe the game you want to play, and Axiom Worlds will use its AI system, known as **Axiom**, to help generate the game world, gameplay mechanics, physics, and other core elements. Before generation begins, users will be shown a preview of their idea, giving them a visual reference to work from when developing and editing their game.

Once inside the Workshop, users can watch their game take shape, load the preview, test their creation, and make changes by simply describing what they want to improve.

From platformers and exploration games to obstacle courses, survival experiences, and imaginative low-poly worlds, Axiom Worlds aims to make game creation accessible to people without requiring extensive programming or game development experience.

**Your prompt. Your world. Your game.**

## 🌟 What Is Axiom Worlds?

Axiom Worlds is envisioned as a platform where anyone can create playable single-player games by describing their ideas in natural language.

Traditional game development often requires knowledge of programming, physics systems, 3D modeling, level design, and game engines. Axiom Worlds aims to simplify this process by allowing users to communicate their ideas to an AI system and have it help construct a playable experience.

Rather than building every object, mechanic, and environment manually, users will describe what they want, review an initial preview, and enter the Workshop to develop their game further.

Axiom Worlds is designed around three main principles:

- **Create:** Describe a game idea and let Axiom begin generating its foundations.
- **Customize:** Enter the Workshop, preview the game, and refine it with prompts.
- **Play:** Launch the finished creation and return to it whenever you want.

The goal is to give players the freedom to become game creators without making traditional game development knowledge a requirement.

## 🤖 1. Meet Axiom — Your AI Game Creator

At the center of Axiom Worlds is **Axiom**, the planned AI system responsible for interpreting user prompts and helping generate game content.

Axiom is intended to understand descriptions of gameplay, environments, characters, objects, physics, and interactive elements, then translate those ideas into a game that users can refine.

Instead of requiring users to manually configure every part of a game, Axiom aims to make creation feel like a conversation.

### Planned Capabilities

- Interpret natural-language descriptions of game ideas.
- Help generate game environments and level layouts.
- Create and configure gameplay mechanics.
- Generate or configure physics for supported objects and interactions.
- Help establish movement, collisions, gravity, and other gameplay behaviors.
- Create interactive objects and environmental elements.
- Assist with character customization systems.
- Generate AI-controlled characters or bots that can interact with the player.
- Apply requested changes to an existing game.
- Help users troubleshoot and refine their creations.

### Example Prompt

> Create a low-poly adventure game where I explore a floating island, jump between platforms, collect crystals, and avoid moving obstacles. Add gravity, responsive movement, and a checkpoint system.

Axiom would interpret the request and help construct an initial version of the game, with the intended gameplay and physics available for preview and further editing.

The exact complexity of generated games will depend on the capabilities implemented during development.

## 🎮 2. Create Games Using Prompts

The main way to create a game in Axiom Worlds will be through a text-based prompt interface.

Users will describe the game they want to build without needing to write code manually.

Prompts can describe the type of game, its environment, mechanics, objectives, characters, and other gameplay details.

### Planned Capabilities

- Create game concepts from written descriptions.
- Specify gameplay genres and objectives.
- Describe environments, levels, and world layouts.
- Define player movement and interactions.
- Request obstacles, collectibles, hazards, and challenges.
- Describe environmental behavior and physics.
- Add new mechanics through follow-up prompts.
- Refine an existing game without rebuilding the entire project from scratch.

### Example Prompts

**Platformer:**

> Make a low-poly platformer with floating islands, moving platforms, checkpoints, and a finish line.

**Exploration game:**

> Create a peaceful low-poly forest with rivers, hills, hidden paths, and collectibles scattered around the world.

**Obstacle course:**

> Build a challenging obstacle course with rotating platforms, swinging hazards, moving blocks, and checkpoints.

**Survival game:**

> Create a single-player survival game in a low-poly desert where I collect resources, avoid hazards, and try to reach a safe location.

These prompts represent examples of the types of experiences Axiom Worlds aims to support. Actual results will depend on the AI system and supported game mechanics.

## 🛠️ 3. The Workshop — Where Games Come to Life

The **Workshop** is planned to be the central workspace where users develop, inspect, test, and edit their generated games.

After entering a game prompt and reviewing the initial preview, users will be able to enter the Workshop to begin working on their creation.

The Workshop is intended to provide a visual environment for watching the game take shape while giving users control over how it develops.

### Planned Workshop Features

- A dedicated workspace for each game project.
- AI-assisted generation of game elements.
- A view of the game's development progress.
- Access to the generated preview.
- The ability to load and test the preview.
- Prompt-based editing of game mechanics and environments.
- Support for refining existing gameplay.
- The ability to request new objects, obstacles, and interactive elements.
- A workflow for moving between editing and playing.

### Example Workshop Workflow

1. Enter a prompt describing your game.
2. Review the preview generated from your idea.
3. Enter the Workshop to begin developing the game.
4. Allow Axiom to generate the requested world and mechanics.
5. Load the preview to test the current version.
6. Identify anything you want to change.
7. Enter a new prompt describing the changes.
8. Review the updated result and repeat as needed.

The goal is to make game development more visual, interactive, and approachable, with the AI handling as much of the technical work as possible.

## 👁️ 4. Preview Before You Build

Axiom Worlds is planned to show users a preview of their game idea before they begin the main generation process.

This preview will serve as a visual reference for the game the user intends to create.

Rather than immediately committing to a particular direction, users will be able to review the concept and use it as a guide when working in the Workshop.

### Planned Preview Capabilities

- Display a visual representation of the proposed game.
- Give users an initial impression of the world and its layout.
- Help establish a reference point for later edits.
- Allow users to load the preview for inspection or testing, where supported.
- Provide a starting point for prompt-based improvements.
- Help users identify changes they want before or during generation.

### Example

A user enters:

> Create a low-poly game where I climb a giant mountain with narrow paths, wooden bridges, and dangerous falling rocks.

Axiom Worlds would first present a preview representing the intended game concept.

The user could then review the preview and decide whether the design matches their expectations before continuing into the Workshop.

The preview is intended to act as a reference for development, rather than a guarantee that every detail of the final game will look or behave exactly the same.

## ⚙️ 5. AI-Generated Physics

Axiom Worlds will use Axiom to generate or configure physics and gameplay mechanics based on user prompts.

**Planned features:**
- Gravity, jumping, and player movement.
- Collision detection and object interactions.
- Moving platforms and obstacles.
- Physics-based puzzles and environmental hazards.
- Checkpoints and respawning systems.
- Adjustable physics through prompts.

**Example prompt:**

> Increase the player's jump height, reduce gravity, and make the moving platforms slower.

The goal is to make game physics easier to create without requiring users to configure everything manually.

## ✏️ 6. Prompt-Based Game Editing

Users will be able to edit their games by describing changes in the Workshop.

Instead of rebuilding a game from scratch, they can ask Axiom to modify supported elements.

**Planned features:**
- Add, remove, or modify objects.
- Change environments and level layouts.
- Adjust game difficulty and physics.
- Add new mechanics and challenges.
- Refine existing gameplay.

**Example:**

> Add a double jump, create three new floating islands, and put a checkpoint before the final obstacle.

Axiom will aim to apply requested changes while preserving unaffected parts of the game.

## 🤖 8. AI Bots and Interactive Characters

Users will be able to create AI-controlled characters, called bots, to populate their worlds.

These bots will be separate from Axiom, which is the AI responsible for helping create and edit games.

**Potential bot behaviors include:**
- Friendly companions that follow the player.
- Enemies that patrol or chase the player.
- Guides that explain objectives.
- Characters that perform tasks.
- Interactive characters with dialogue, where supported.

**Example prompt:**

> Create a friendly robot that follows me and helps me find hidden collectibles.

More advanced conversational features will depend on the AI technology available during development.

## 💾 9. Save Games on Your PC

Axiom Worlds is planned to save games as folders on the user's computer.

This means users can keep their creations, reopen them, edit them, and play them again without recreating everything from the beginning.

**Planned features:**
- Save worlds locally.
- Keep each game in its own folder.
- Reopen and edit saved worlds.
- Launch saved games whenever desired.
- Copy and back up game folders.
- Preserve supported game data between sessions.

An example folder structure might look like this:

    MyWorld/
    ├── assets/
    ├── characters/
    ├── physics/
    ├── world-data/
    └── world-config.json

This structure is only an example; the actual file format has not been decided.

Some AI features may require an internet connection, depending on the final implementation.

## 📦 10. Share Worlds With Friends

Since games will be saved as folders, users will be able to share their creations by sending those folders to friends.

**How sharing is intended to work:**

1. Create and save a world.
2. Locate its folder on your computer.
3. Send the folder to a friend.
4. Have them import or open it in Axiom Worlds.
5. Let them play their own copy.

Worlds will need to contain the required files and be compatible with the recipient's version.

**Important:** Sharing worlds does not mean multiplayer is supported. Axiom Worlds is designed for single-player experiences, with each person playing their own copy.
